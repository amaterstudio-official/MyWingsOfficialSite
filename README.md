MyWings 2026 – Official Website

The official website of MyWings 2026, an independent open-source flight simulator developed by Amater Studio.

🌐 Website: https://amaterstudio-official.github.io/MyWingsOfficialSite/

---

About

MyWings 2026 is an open-source flight simulator project built with Unreal Engine 5.

This repository contains the source code for the official MyWings 2026 website. It serves as the central place for information about the simulator, development progress, available downloads, screenshots and announcements.

Website Sections

- Home – Introduction to MyWings 2026.
- About – Information about the project.
- Features – Overview of simulator features.
- Aircraft Fleet – Aircraft featured or planned for MyWings.
- Gallery – Screenshots and visual previews.
- Download – Available game versions.
- Release Archive – Previous public releases.
- Trailer – Official project videos.

Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

Run Locally

You can view the website locally without installing additional software.

1. Clone this repository:
   git clone https://github.com/AmaterStudio-Official/MyWingsOfficialSite.git
2. Open the downloaded folder.
3. Open "index.html" in your web browser.
