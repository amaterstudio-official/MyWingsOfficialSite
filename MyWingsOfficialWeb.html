The project

About MyWings

Built with passion for next-gen flight simulation.

MyWings is built from the ground up in Unreal Engine 5. The project focuses on an accessible, realistic, and customizable simulator for aviation enthusiasts. It is an independent project in development, so features and aircraft may change between versions.

What makes it fly

Key Features

The technology and features behind the project.

Advanced Aerodynamics

A custom flight physics system focused on lift, drag, and aircraft behavior in flight.

Cesium World Integration

Cesium geographic data for large-scale environments and world exploration.

Innsbruck Airport (LOWI)

Innsbruck Airport as one of the main locations for flying.
